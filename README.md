# Gölge Ağ

Tarayıcıda çalışan, tamamen kurgusal ve kısa bir terminal gerilim / rol yapma oyunu.

**[Oyunu şimdi oyna](https://berkantkull.github.io/darkweb-game/)**

## Oyunda neler var?

- Özel yeteneklere ve farklı finallere sahip 10 karakter
- Türk alfabesi şifresi, binary ve HEX çözücüleri
- Kayıt analizi ve üç seviyeli kablo birleştirme görevi
- İz, güven ve süreye göre değişen oyun akışı
- Masaüstü ve mobil cihazlar için responsive arayüz
- Ses ve azaltılmış hareket ayarları

## Oynama

GitHub Pages bağlantısını açman yeterli. Kurulum gerekmez. Kablo görevinde bilgisayarda yön tuşlarını, telefonda kaydırma hareketini veya ekrandaki yön düğmelerini kullanabilirsin.

## Yerel kullanım

Projeyi indirip `index.html` dosyasını tarayıcıda aç. Oyun yalnızca HTML, CSS ve JavaScript kullanır; ek bağımlılık gerekmez.
